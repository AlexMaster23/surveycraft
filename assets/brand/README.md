# SurveyCraft brand assets

The SurveyCraft identity is original artwork created for this project. It shares CADCraft's simple
rounded-square product-family language without copying the CADCraft set-square drawing.

## Files

- `surveycraft-mark.svg` — square total-station mark for the GitHub avatar and extension catalog.
- `surveycraft-mark-64.png`, `surveycraft-mark-256.png`, `surveycraft-mark-1024.png` — checked
  raster exports for small UI, catalog and repository use.
- `surveycraft-lockup.svg` — horizontal wordmark for README and website headers.
- `surveycraft-lockup.png` — rendered wordmark preview.

## Palette

- orange `#F47A20`
- ink `#111317`
- cream `#F4EEE4`
- cyan accent `#27C2D6`

Keep the SVG as the source of truth and regenerate raster sizes from it after any approved edit.
