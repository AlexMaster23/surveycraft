# Contributing to SurveyCraft

Thank you for helping build open surveying tools.

Start with [BLUEPRINT.md](BLUEPRINT.md), then read [AGENTS.md](AGENTS.md). New behavior needs a
small synthetic fixture, documented units/tolerances and tests at the lowest possible layer.

Please keep pull requests focused and include:

- what surveying workflow changes;
- the public standard or independent mathematical reference used;
- how invalid and non-finite input is handled;
- how the result was verified;
- whether the CAD operation is fully undoable.
