# Security

Do not report vulnerabilities in public issues. Until a dedicated security address exists, use
GitHub's private vulnerability-reporting feature for the SurveyCraft repository.

SurveyCraft treats imported survey files, project JSON, extension packages and CAD geometry as
untrusted input. Reports should include the affected version, a minimal synthetic reproducer and
the impact. Do not attach production cadastral data, credentials, license material or proprietary
software files.
